# 🌱 디스코드 농장 게임 봇

친구들과 심기 → 성장 → 수확 → 판매 → 밭 확장을 즐기는 Python 시제품입니다.
농장은 디스코드 계정당 하나이며 모든 서버에서 공유합니다.

## 처음 실행하기 (Windows)

1. Python 3.12 이상을 설치합니다.
2. 이 폴더에서 터미널을 열고 다음을 실행합니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

3. [Discord Developer Portal](https://discord.com/developers/applications)에서 애플리케이션을 만들고 Bot 화면에서 토큰을 발급합니다. `.env`의 `DISCORD_TOKEN=` 뒤에 입력합니다. 토큰은 비밀번호처럼 관리하며 채팅이나 GitHub에 올리지 않습니다.
4. Discord에서 개발자 모드를 켜고 테스트할 서버의 ID를 복사해 `.env`의 `TEST_GUILD_ID=`에 입력합니다.
5. Developer Portal의 OAuth2 URL Generator에서 `bot`, `applications.commands` 범위를 선택하고, 봇 권한으로 채널 보기·메시지 보내기·링크 첨부를 선택해 생성된 링크로 테스트 서버에 초대합니다. Message Content 같은 특별 권한은 필요 없습니다.
6. 실행합니다.

```powershell
.\.venv\Scripts\python.exe bot.py
```

7. 테스트 서버에서 `/농장`을 실행합니다. 당근 심기 → 1분 대기 → 작물 그림 자동 변경 확인 → 수확 → 판매를 확인하세요. 터미널을 닫으면 봇도 종료됩니다.

`TEST_GUILD_ID`를 비우고 재실행하면 전체 서버용 명령어로 등록합니다. 기존 테스트 서버에 남은 명령어는 별도로 정리해야 할 수 있습니다. 처음에는 테스트 서버만 사용하세요.

여러 서버에 즉시 등록하려면 `TEST_GUILD_ID`에 서버 ID를 쉼표로 구분해 입력하세요. 봇이 각 서버에 초대되어 있어야 합니다.

## 기능

| 명령어 | 사용법 |
|---|---|
| `/농장` | 5×5 밭, 작물·가로줄 선택, 전체 심기·수확·판매, 줄 확장 |
| `/상점` | 🌱 씨앗 / 🌿 비료 / 🧰 농장 용품 카테고리에서 구매 |
| `/가방` | 씨앗·수확물 수량·판매가·보유 최대 무게·개인 최고 기록 |
| `/판매` | crop 선택 시 해당 작물 전부, 생략 시 전체 판매. 작물별 판매 개수·받은 골드·합계 표시 |
| `/순위` | scope으로 서버/전체 선택, crop 선택 시 무게, 생략 시 판매 수익 |
| `/도움말` | 규칙 확인 |
| `/출석` | 매일 30G, 연속 7일마다 추가 100G 수령 (한국 시간 자정 기준) |

모든 작물의 씨앗은 상점에서 5개·25개 단위로 구매합니다. 기존 보유 씨앗은 일회성 패치로 다음 5의 배수까지 무료 보충했습니다(1~4개 → 5개, 6~9개 → 10개). 0개와 이미 5의 배수인 수량은 유지합니다. 재실행해도 이 보정은 중복 지급되지 않습니다.

`/농장`은 채널에 구경용 공개 농장을 표시합니다. 밭 상태와 🌿 내 농장 열기 버튼만 보이며, 심기·수확·판매·상점 메뉴는 노출하지 않습니다. 누가 버튼을 눌러도 그 사람 자신의 농장을 본인에게만 보이는 개인 화면으로 엽니다. 공개 화면에는 농장 주인의 이름을 표시합니다.

개인 화면 하단의 🏪 상점과 🌿 비료 사용 버튼으로 이동할 수 있으며, 🌿 농장으로 버튼으로 같은 개인 화면에 돌아옵니다. 구매·심기·수확·판매·확장·비료 예약을 하면 해당 사용자가 현재 채널별로 가장 최근에 연 공개 농장도 함께 갱신됩니다. 다른 사람의 조작 화면은 보거나 사용할 수 없습니다.

작물은 밭 개방 단계에 따라 구매·심기가 열립니다. 1번 밭: 감자·당근·호박, 2번 밭: 오이·가지·딸기 추가, 3번 밭: 토마토·포도 추가, 4번 밭: 배·귤 추가, 5번 밭: 쌀·목화 추가. 잠긴 작물은 메뉴에 🔒와 필요한 밭 번호를 표시하고 구매 버튼을 비활성화합니다. 기존 씨앗과 수확물은 삭제하지 않으며, 이미 심어진 작물은 계속 성장·수확할 수 있습니다.

1번 밭은 첫 번째 가로줄 5칸 전체입니다. 1~5번 밭을 모두 표시하며 잠긴 밭은 🔒로 표시합니다. 다음 밭 확장을 구매하면 해당 밭이 열립니다. 기본값은 당근과 1번 밭이며, 열린 밭 전체도 선택할 수 있습니다. 선택한 범위의 빈 칸에만 심고 씨앗이 부족하면 전체 심기를 취소합니다.

성장 완료 시 공개 농장과 열려 있는 개인 농장 화면이 자동 갱신됩니다. 비공개 메시지를 수정할 수 있는 Discord 토큰의 시간 제한 때문에 개인 농장은 마지막 조작 후 14분간 유효합니다. 만료되면 공개 화면의 내 농장 열기를 다시 누르세요. 상점·비료 사용 화면은 3분간 유효합니다. 개인 화면이 만료돼도 공개 농장의 성장 자동 갱신과 저장된 작물의 성장은 계속됩니다. 매초 메시지를 수정하지는 않습니다.

완료 예정은 `당근 · 성장 1분 · 10/24 21:30:00 완료`처럼 고정 성장 시간과 한국 시간 완료 시각으로 표시합니다. 기기 시계에 따라 다르게 보일 수 있는 Discord 상대시간 카운트다운은 사용하지 않습니다. 새로 심는 작물에는 심은 시각과 적용된 성장 시간도 함께 저장합니다.

봇 재시작 후에는 `/농장`을 다시 열어 공개 농장의 자동 갱신을 재개해 주세요. 이전 공개 화면의 내 농장 열기 버튼은 재시작 후에도 사용할 수 있습니다. 업데이트 전에 보낸 예전 농장 메시지에는 이전 메뉴가 남아 있을 수 있으므로 새 화면을 사용하세요.

## 임시 밸런스와 확정한 구현 규칙

`balance.json`에서 수정합니다. 가격은 플레이 테스트용이며 확정된 경제 밸런스는 아닙니다.

| 작물 | 성장 | 씨앗 가격 | 기본 판매가 | 기본 무게 | 기본 크기 기준 칸당 시간당 순수익 |
|---|---:|---:|---:|---:|---:|
| 🥔 감자 | 30초 | 2G | 6G | 150g | 480G |
| 🥕 당근 | 1분 | 5G | 14G | 100g | 540G |
| 🎃 호박 | 5분 | 10G | 60G | 2,000g | 600G |
| 🥒 오이 | 10분 | 20G | 130G | 300g | 660G |
| 🍆 가지 | 15분 | 30G | 210G | 250g | 720G |
| 🍓 딸기 | 30분 | 60G | 450G | 20g | 780G |
| 🍅 토마토 | 1시간 | 100G | 940G | 200g | 840G |
| 🍇 포도 | 2시간 | 200G | 2,000G | 500g | 900G |
| 🍐 배 | 4시간 | 400G | 4,240G | 600g | 960G |
| 🍊 귤 | 8시간 | 800G | 8,960G | 100g | 1,020G |
| 🌾 쌀 | 12시간 | 1,200G | 14,160G | 1,000g | 1,080G |
| ☁️ 목화 | 24시간 | 2,400G | 29,760G | 200g | 1,140G |

가격은 임시 설정입니다. 기본 크기에서 시간당 순수익은 감자 480G부터 목화 1,140G까지 성장 시간순으로 60G씩 높였습니다. 실제 판매가는 무작위 무게·새 피해·반올림에 따라 달라집니다. 기존에 심은 작물의 완료 시각과 수확물의 저장된 판매가는 유지합니다. 모든 씨앗은 5개·25개로 구매합니다.

위 수익은 대기 없이 반복할 때의 비교용이며 무작위 크기·새 피해·반올림을 제외합니다. 긴 작물은 조작 횟수와 기본 시간당 수익에서 이점이 있습니다.

- 시작: 100G, 첫 줄 5칸, 당근 씨앗 5개. 다른 명령어로 먼저 접근해도 시작 보상은 한 번만 지급합니다.
- 확장: 100 / 400 / 1,000 / 2,500G, 위에서부터 한 줄씩 영구 개방.
- 무게: 수확 시 90%는 기본 무게의 0.70~1.30배, 9%는 1.30~2.00배, 1%는 2.00~3.00배에서 균등 추첨하고 정수 g로 반올림. 등급은 보통 / 1.1배 이상 큼 / 1.5배 이상 희귀 / 2배 이상 전설. 반올림 때문에 등급 비율과 추첨 구간 비율은 정확히 일치하지 않습니다.
- 판매가: `기본 판매가 × 무게/기본 무게 × 새 피해 배율`, 정수 반올림, 최소 1G.
- 새: 심을 때 작물당 한 번 5% 판정, 해당 작물 판매가 10% 감소. 크기 기록은 영향 없음.
- 허수아비: 300G, 영구 적용, 구매 후 심는 작물부터 보호.
- 작물은 시들지 않으며 성장 완료 시각으로 오프라인 성장을 계산합니다.
- 서버 순위: 해당 서버에서 봇을 이용한 사용자의 전체 기록. 탈퇴 여부는 확인하지 않습니다. 전체 기간 상위 10명, 동점은 계정 ID 순서.
- 무게 기록과 판매 수익은 판매·구매 이후에도 유지됩니다. 시작 골드는 판매 수익에 포함하지 않습니다.
- 출석은 `/출석` 또는 개인 농장의 📅 출석 보상 받기로 수령합니다. 한국 시간 자정마다 새 날짜로 계산하며 계정당 모든 서버에서 하루 한 번만 받을 수 있습니다. 매일 30G, 연속 7·14·21일째에는 추가 100G를 지급합니다. 하루를 건너뛰면 다음 출석은 연속 1일부터 시작하고 기존 골드는 차감하지 않습니다. 출석 보상은 누적 판매 수익 순위에 포함되지 않습니다. 금액과 보너스 주기는 `balance.json`에서 조정합니다.
- 수확 결과에서 작물별 첫 무게 기록과 개인 신기록을 표시합니다. 여러 개를 한 번에 수확해도 작물별 최종 최고 무게만 한 번 표시하며, 동점이나 기존 기록 이하일 때는 알리지 않습니다. 별도 채팅 메시지는 보내지 않습니다.
- 성장 비료: 1개 5G. 농장의 🌿 비료 사용 → 빈 밭 한 줄 선택 → 다음 심기에 사용. 심기에 성공할 때 1개를 소모해 해당 밭의 성장 시간을 20% 줄입니다(예: 감자 24초 / 당근 48초 / 목화 19시간 12분). 무게·수확량에는 영향을 주지 않습니다.
- 비료 예약은 보유 개수 안에서만 가능하고 한 밭에 중복 예약할 수 없습니다. 작물이 있는 밭이나 잠긴 밭에는 예약할 수 없습니다. 예약 취소·씨앗 부족·심기 실패 시 소모되지 않습니다. 전체 심기는 예약된 각 밭에만 1개씩 적용합니다. 예약과 보유량은 재시작해도 유지됩니다.
- 시즌·알림·상시 운영 배포는 포함하지 않습니다.

## 저장 및 검증

SQLite 파일 `data/farm.db`에 저장합니다. 구매·심기·수확·판매·확장은 하나의 저장 작업으로 처리되며 실패하면 전부 취소합니다. 화면 버전 검사로 같은 화면의 연속 클릭을 막고 Discord 요청 ID로 같은 요청을 다시 처리하지 않습니다. 다른 화면에서 농장이 바뀌면 명령어를 다시 열어야 합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

자동 검사는 시작 보상·재시작·성장 시간·동시 클릭·중복 요청·씨앗 부족·확장·판매 기록·서버 순위·허수아비를 확인합니다. 실제 Discord 연결과 버튼 동작은 토큰 설정 후 별도 확인이 필요합니다.

수동 확인: 두 계정으로 시작 → 서로 다른 농장 확인 → 30초 농사 → 봇 종료/재시작 → 수확/판매 → 두 서버에서 같은 계정의 농장과 순위 비교 → 빠르게 버튼 두 번 클릭 → 오래된 화면에서 구매 취소 확인.

백업할 때는 봇을 종료한 뒤 `data` 폴더 전체를 복사하세요. 복원도 봇을 종료한 상태에서 합니다. 설정을 바꾸면 새 심기·새 수확부터 계산에 반영되므로 운영 중 경제 설정 변경에는 주의하세요.
